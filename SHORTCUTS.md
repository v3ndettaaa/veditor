# veditor Keyboard Shortcuts Reference

`veditor` provides keyboard shortcuts for almost every tool, navigation action, and setting to give you an ultra-fast desktop-like experience.

## Tools
| Shortcut | Action | Description |
|---|---|---|
| `V` | **Select Tool** | Select, move, resize, rotate, or align annotations |
| `P` | **Freehand Pen** | Pressure-sensitive ink pen with Catmull-Rom spline smoothing |
| `H` | **Highlighter** | Translucent marker with Multiply blend mode |
| `E` | **Eraser** | Smart eraser (Stroke, Object, and Pixel modes) |
| `R` | **Rectangle** | Draw rectangles with optional fill and border styles |
| `O` | **Ellipse** | Draw circles and ellipses |
| `L` | **Line** | Draw straight lines |
| `A` | **Arrow** | Draw directional pointer arrows |
| `T` | **Text Box** | Rich text box insertion |
| `M` | **Stamp** | Insert built-in vector stamps (APPROVED, CONFIDENTIAL, etc.) |
| `C` | **Callout** | Speech bubble with directional pointer |
| `K` | **Signature** | Digital ink signature pad |
| `X` | **Redaction** | Permanent blackout / whiteout redaction box |
| `Z` | **Laser Pointer** | Ephemeral glowing presentation pointer |

---

## Global & View Controls
| Shortcut | Action | Description |
|---|---|---|
| `Cmd + K` / `Ctrl + K` | **Command Palette** | Instant search for all tools, commands, and settings |
| `Cmd + Z` / `Ctrl + Z` | **Undo** | Revert previous action |
| `Cmd + Shift + Z` / `Ctrl + Y` | **Redo** | Redo reverted action |
| `Cmd + +` / `Ctrl + +` | **Zoom In** | Increase canvas zoom by 15% |
| `Cmd + -` / `Ctrl + -` | **Zoom Out** | Decrease canvas zoom by 15% |
| `0` | **Fit to Width** | Fit page to window width |
| `F` | **Focus Mode** | Hide all toolbars and side panels for distraction-free reading |
| `?` | **Shortcuts Help** | Display keyboard shortcuts reference overlay |
| `Esc` | **Dismiss** | Close active modals, command palette, or deselect elements |

---

## Stylus & Touch Controls
| Input | Action |
|---|---|
| **Stylus Inverted Tip** | Automatically activates Eraser tool |
| **Stylus Barrel Button** | Quick-select / lasso selection |
| **Two-Finger Pinch** | Smooth pinch-to-zoom |
| **Two-Finger Drag** | Two-finger document pan |
| **Palm on Screen** | Automatically rejected (Palm Rejection Engine) |
